# تشغيل سيرفر WireGuard الخاص بك — دليل عملي (لغير المختصين)

> القاعدة الذهبية: الأمر يُشغَّل على **لينكس (أوبونتو)** فقط.
> **ليس** في Termux (أندرويد يمنع إنشاء أنفاق VPN للتطبيقات) و**ليس** في
> PowerShell (ويندوز لا يفهم أوامر لينكس ولا iptables).

## الخيار 1 — الأسهل: VPS رخيص ببطاقة صديقك (10 دقائق، ~4-6$/شهر)
يناسب صديقاً خارج البلد **بلا أي خبرة لينكس**. أمثلة مزودين: Hetzner / Contabo / Netcup.
اختر الدولة = دولة خروجك (ألمانيا أو هولندا أو فنلندا).

1. صديقك ينشئ حساباً ويدفع ببطاقته (أرخص خطة VPS بذاكرة 2GB تكفي).
2. ينشئ سيرفراً جديداً بنظام **Ubuntu 24.04** (جاهز مثبتاً مسبقاً).
3. يفتح **Console** (طرفية من المتصفح — لا يحتاج برامج).
4. ينسخ ملف `setup-wg-server.sh` من هذا المستودع إلى السيرفر ثم يشغّل:
   ```bash
   sudo bash setup-wg-server.sh 5 443
   ```
5. يجد الملفات في مجلد `wg-clients` ويرسلها لك على تلغرام.
6. أنت: استيراد في WG Auto ← تظهر الأعلام ← فحص ← اتصال. انتهى.

> ملاحظة: بعض المزودين يحجب المنفذ 25 (بريد) افتراضياً — لا يهمنا، نستخدم 443.

## الخيار 2 — مجاني تماماً: ويندوز صديقك + WSL (أوبونتو بنقرة)
إن كان لدى صديقك ويندوز 10/11 وجهازه يعمل غالباً:

1. من متجر Microsoft يثبّت **WSL + Ubuntu** (مجاني، نقرة واحدة) ثم يفتحه.
2. داخل طرفية أوبونتو يشغّل نفس الأمر:
   ```bash
   sudo bash setup-wg-server.sh 5 443
   ```
3. خطوتان إضافيتان لا مفر منهما في البيوت:
   - فتح/تحويل المنفذ 443 في راوتر البيت نحو جهازه (Port Forwarding).
   - عنوان البيت يتغير دورياً — ثبّته بخدمة مجانية مثل DuckDNS.
4. يرسل لك الملفات (مع تعديل سطر Endpoint لعنوان DuckDNS إن تغيّر).

## الخيار 3 — راسبيري باي أو لابتوب قديم عند صديقك
نظام Raspberry Pi OS أو Ubuntu، نفس الأمر الواحد، والجهاز يعمل باستمرار.
الأفضل لمن يملك القطعة أصلاً.

## بعد وصول الملفات إليك
1. احفظ `client1.conf` من تلغرام.
2. في WG Auto: تبويب الكونفيجات ← استيراد ← اختر الملف.
3. سيظهر العلم + `⏳` لا يوجد (ملفاتك بلا انتهاء) ← فحص ← تفعيل.
4. كل جهاز في العائلة يأخذ ملفاً مختلفاً (client2, client3...).

## أسئلة سريعة
- **Termux على أندرويد؟** لا — يحتاج روت عميق وصلاحيات نواة غير متاحة.
- **PowerShell على ويندوز؟** لا — السكربت لينكس. على ويندوز استخدم الخيار 2 (WSL).
- **السيرفر يستهلك؟** خفيف جداً (WireGuard يستهلك ميجابايتات ويعمل على أضعف جهاز).
