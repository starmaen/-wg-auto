# WG Auto

تطبيق أندرويد: كونفيجات WireGuard + خوادم DNS + MTU (1000–1500) مع اختيار تلقائي للأفضل
ومراقبة تبدّل الشبكة في الخلفية.

## البناء على GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع جديد (الفرع main).
2. تبويب Actions → Build APK (يعمل تلقائياً مع كل push أو يدوياً Run workflow).
3. بعد انتهاء البناء: افتح التشغيلة ← Artifacts ← WGAuto-debug-apk.

## الاستخدام
- تبويب الكونفيجات: استيراد ملفات .conf أو لصق النص، تفعيل/تعطيل/حذف.
- تبويب DNS: إضافة/حذف/تفعيل، واختبار السرعة.
- زر تشغيل: يفحص كل الكونفيجات المفعّلة ثم يتصل بالأفضل.

## تبويب VPN 🌍 (جديد في 1.28 — OpenVPN مدمج داخل التطبيق)
سيرفرات OpenVPN مجانية من VPNGate (جامعة تسوكوبا، بلا حساب) بجانب WireGuard — **بلا أي تطبيق خارجي**:
- **مدمج بالكامل**: نواة ics-openvpn المفتوحة (GPLv2) مضمّنة في التطبيق — الاتصال والفصل بزر واحد من الداخل.
- **تحديث تلقائي**: القائمة تُجلب من `https://www.vpngate.net/api/iphone/` وتُدمج مع الكاش (سيرفرات اختفت منذ أقل من 48 ساعة تبقى لتنويع الدول).
- **فحص بنفس معادلة التطبيق**: الزمن 50% + الفقد 30% + التذبذب 20% (TCP أولاً ثم Ping)، مع ميداليات 🥇🥈🥉.
- **يدوي أو تلقائي**: شرائح البروتوكول (تلقائي / UDP أسرع / TCP يتجاوز الجدران)، شرائح الدول مع الأعلام 🇩🇪، وبحث بالاسم/IP.
- **حالة حية**: 🟢 يعمل / 🔴 لا يعمل / ⚪ لم يُفحص لكل سيرفر، وشريط علوي يظهر الاتصال الداخلي مع زر **فصل ⏻**.
- **نفق واحد فقط**: تشغيل OpenVPN يوقف WireGuard تلقائياً والعكس صحيح.
- ملاحظة صدق تقني: قائمة VPNGate تطغى عليها بعض الدول في بعض الأيام (تطوعية)؛ DNS وMTU للـ OpenVPN يُدفعان من الكونفيج عند الاتصال.
